# Context Pack

**Style Preset**: teaching-clean
**Output Mode**: html-only

## Project Goal
让学员理解 AI 做 Slides 不是一次性生成，而是一条可复用的生产管线。

## Audience
- Primary: AI 课程学员
- Pain / Curiosity / Decision context: 想把粗糙想法变成可展示结果

## Key Claims
- Slides 生产需要 Gate、Style Lock 和可见交付。
- Prompt 是资产，图片只是结果。
- HTML 是一等输出形态。

## Forbidden Zones
- 不把产品说成一键万能。
- 不让页面塞满文字。
