# Project Brief

**Deck Title**: Editorial Magazine Mixed Demo
**Audience**: Product manager / training-camp reviewers
**Use Case**: Browser visual acceptance for editorial-magazine
**Output Mode**: mixed
**Style Preset**: editorial-magazine

## Goal

Show that `editorial-magazine` can carry a Mixed deck where selected pages embed local slide images while still using the same `build_html.py` renderer.

## Constraints

- Do not hand-write `index.html`.
- Keep the sample small enough for quick regression.
- Use repository-local placeholder PNGs, not API-generated images.
- Exercise the existing layout snippets without custom per-page HTML templates.
