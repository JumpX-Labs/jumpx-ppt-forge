# Design Spec — 上市的，不是火箭

## 设计意图
一份"有立场的杂志跨页"。用 editorial 的重量感承载一个反直觉论点：把读者的注意力从火箭（性感但一次性）搬到 Starlink（朴素但经常性）。视觉上靠**超大衬线标题 + 单一品牌红 + 深色封面/金句页**制造张力，靠**数字/词锚**把抽象的商业逻辑钉成一眼能记的画面。

## 风格锁（见 `style_lock.json`）
- 配色：纸 `#F1EFEA` / 墨 `#0A0A0B` / 单一 accent 红 `#E0472E` / 次文字 `#5E5A52` / 描边 `#D8D1C3`。
- 字体：标题衬线 `Georgia / Noto Serif SC`；正文 `Inter / Noto Sans SC`。
- 密度：medium；layout_bias：magazine。

## 每页视觉决策
| 页 | layout | 视觉手艺要点（对应 08 craft rules） |
|----|--------|--------------------------------------|
| P01 封面 | cover | 深色整页；104px 衬线 hero，"不是火箭"红色；单一焦点、大留白 |
| P02 反框架 | comparison | 左右对照（火箭 vs Starlink）+ accent 竖分隔线；右栏强调 |
| P03 真正的引擎 | big-idea | 128px 衬线词锚"经常性" + 右侧迷你账本；数字 `tabular-nums`；底部 11px 注脚标注"逻辑示意，非财报" |
| P04 护城河 | framework | ①→②→③→④ 编号动线（非等大卡片）；收束句"成本→订阅利润" |
| P05 历史意义 | quote | 深色整页；66px 衬线金句，"现金流生意"红色强调 |
| P06 收尾 | closing | 三条判断点（字号有层级）+ 大号红色记忆点单独成行 |

## 反廉价约束（已并入 `style_lock.forbidden[]`）
禁灰 SaaS 卡片 / 廉价渐变 / 贴纸堆 / 商务剪贴画 / 小字；不堆全居中等大灰卡片网格；不编造精确财务数字当事实。
